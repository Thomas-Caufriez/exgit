1:  - Markdown est un language de balise simple permettant de formatter des éléments textuels

2:  - Il permet de créer des fichiers de textes avec un minimum de style comme des texts en gras, des titres, des paragraphes...
    - Il est souvent utilisé pour faire des fichiers reamde dans les projets en code

3:  - Le format peut être utilisé pour tout, sites webs, documents, notes, livres, ...
    - Il peut être ouver par n'importe quel autre éditeur de texte
    - Markdown restera dans le temps et sera toujours lisible via un éditeur de texte simple
    - Il y a déjà énormément d'applications et de sites qui utilisent Markdown, c'est donc une référence
